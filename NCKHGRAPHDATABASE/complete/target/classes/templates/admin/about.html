Mục tiêu hệ thống

Dự án hỗ trợ phát hiện dấu hiệu lừa đảo và tội phạm mạng bằng cách chuyển dữ liệu rời rạc thành đồ thị quan hệ. Admin có thể quan sát cụm nghi ngờ, kiểm tra node liên quan và xem lý do hệ thống đánh giá một thực thể là an toàn, nghi ngờ hoặc gian lận.

  • Phân tích dữ liệu nhập tay, Excel và network capture.
  • Hiển thị quan hệ giữa Email, IP, URL, Domain, File và tài khoản.
  • Cung cấp điểm rủi ro, verdict, indicators và diễn giải theo node.
  • Hỗ trợ quản trị dữ liệu, tài khoản và phiên phân tích.
